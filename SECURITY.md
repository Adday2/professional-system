
# Security Policy

## Supported Versions

This is a portfolio project. The latest code on the `main` branch is the actively maintained version. Older commits and snapshots may not receive security fixes.

## Reporting a Vulnerability

Please do not disclose security vulnerabilities, exploit details, credentials, or sensitive information in public issues or discussions.

- If private vulnerability reporting is enabled for this repository, use GitHub's **Report a vulnerability** feature.
- If private reporting is unavailable, open an issue requesting a private contact method without including vulnerability details.
- Include the affected component, steps to reproduce the issue, its potential impact, and any suggested mitigation when reporting privately.
- Please allow time for the issue to be reviewed and addressed before publicly disclosing technical details.

This project does not offer a bug bounty program.
