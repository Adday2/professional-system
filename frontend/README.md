
# Frontend

This directory contains the React, TypeScript, and Vite frontend for **Professional System**.

For the project's features, architecture, setup instructions, environment configuration, Docker usage, and screenshots, see the [main project README](../README.md).

## Run the frontend locally

Install dependencies and start the Vite development server:

```bash
npm ci
npm run dev
```

Ensure the backend API is running and configured as described in the main README.
